# Presets de vídeo (video-use)

Presets nomeados que reproduzem um acabamento completo num vídeo novo trocando só o
material. Cada preset tem um `<NOME>.md` (fonte de verdade do estilo), um `<nome>.json`
(referência rápida) e os scripts do pipeline.

| Preset | Palavra-chave | O que é | Docs |
|--------|---------------|---------|------|
| **padrão** | `padrão` | Reel 9:16 da clínica (harmonização): gancho com título dourado surgindo de trás da cabeça, legenda Montserrat contínua, transições zoom-punch, grade cinema sutil, retoque só do apresentador (paciente intacta), selo “Passo Fundo”, áudio −14 LUFS. | [`padrao/PADRAO.md`](padrao/PADRAO.md) |

**Como usar:** quando o usuário pedir “edita no **padrão**” (ou a palavra-chave do preset),
leia o `.md` correspondente e siga o fluxo. Edite só o bloco **PER-VIDEO** dos scripts.
